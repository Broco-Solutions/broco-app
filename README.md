# Broco App

Aplicación interna de Broco Solutions para Clientes, Proyectos, Ingresos,
Gastos y Tiempos.

## Desarrollo local

El gestor de paquetes canónico es pnpm:

```bash
pnpm install
pnpm dev
```

Para el entorno de pruebas y los comandos seguros de validación, consultar
`AGENTS.md`. La documentación operativa vigente de producción está únicamente
en [`docs/PRODUCCION.md`](docs/PRODUCCION.md).
